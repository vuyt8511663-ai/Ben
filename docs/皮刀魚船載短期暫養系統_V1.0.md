# 皮刀魚船載短期暫養系統 V1.0
日期：2026-11-13
狀態：概念設計；未經船舶穩性、結構及水質負荷驗證，不得直接施工或滿載。

## 1. 設計目標
- 船型：使用者提供照片所示之沿岸作業漁船。
- 暫養位置：原鮪魚吊運作業艙／艙位。
- 魚種：皮刀（眼眶魚，Mene maculata）。
- 目標數量：500–600尾；實際容量須依魚體平均重量、體長、槽有效水量、換水量及供氧能力試驗決定。
- 暫養期：4–7天。
- 原則：簡易海水直流交換、連續曝氣、獨立備援、可分區隔離；先小量試養。

## 2. 重要生物與工程限制
農業部水產試驗所資料指出皮刀魚身體單薄、游泳力弱，以浮游生物為主食；臺灣魚類資料庫描述其體高側扁、腹緣薄且銳利，主要攝食動物性浮游生物或底棲生物。捕捉、轉運及槽內碰撞風險需特別控制。不可將其他魚種的放養密度直接套用於皮刀魚。
船艙裝水會增加排水量、降低乾舷，並產生自由液面效應；改造前須由合格船舶專業人員評估船體穩性、艙壁承載、重心、吃水、排水及結構。不可直接把原船艙當水槽灌滿。

## 3. 建議構型
- 在原艙內放置獨立、可拆卸、海水適用且表面平滑的槽體（HDPE或合格FRP，材料須確認適用海水及魚類接觸）。
- 以至少3個獨立槽區作概念配置；分隔板須有足夠開孔或獨立水路，避免形成死水區。實際隔間數與尺寸待現場量測及魚體尺寸試驗決定。
- 槽體須有圓滑內角、無尖銳突起，避免魚體擦傷；網具及轉魚設備以柔軟、低摩擦為原則。
- 每槽獨立進水閥、排水閥、溢流防逃網、底部排污口及曝氣支管。
- 槽體需有防浪／消波分隔，但不得造成魚隻夾困或水流死角。

## 4. 海水直流系統
水路：船外適當取水口 → 粗／細濾網 → 海水泵 → 分歧總管及各槽流量閥 → 暫養槽 → 溢流及底排 → 船外安全排放。
- 取水口位置須避開排水口、舷外機／主機排氣、油污區、舱底水及船舶自身污染源；取水口位置由船舶工程人員現勘確認。
- 設置兩台可獨立運作的海水泵（一用一備），電源迴路分開；泵浦流量不可在未量測槽體有效水量及魚隻耗氧前指定。
- 濾網需可快速拆洗，避免堵塞；各槽需可單獨關閉進水與排水。
- 排水口設防逃網及可清理結構，排放不得造成船艙回流或吸入取水口。
- 直流換水不能取代溶氧監測，也不能保證氨氮／CO2安全；需實測流量與水質。

## 5. 曝氣與備援
- 每槽配置柔和、均勻的曝氣管／氣石，避免強水流直接沖擊魚群。
- 主曝氣機與備援供氧（合適規格之氧氣瓶、調壓器、流量計及分配器）分開；氧氣瓶固定、防曬、防油污，通風並依船舶安全規範安裝。
- 供氧系統須可在主電源或曝氣機故障時立即切換；警報及備用電源需獨立考慮。
- 不可只憑氣泡外觀判斷溶氧，必須用校正過的溶氧計測量。

## 6. 監測
至少準備：溶氧計、溫度計、鹽度計／折射計、pH計；並備有總氨氮（TAN）及亞硝酸鹽測試。若條件許可監測CO2。
- 裝魚前記錄取水海域及槽水的溫度、鹽度、溶氧、pH。
- 初期與裝魚後頻繁記錄；穩定後仍至少每班記錄，溶氧建議連續監測並設低氧警報。
- 目標值須依皮刀魚專屬試養數據及水產獸醫／水試單位建議訂定；目前沒有足夠資料支持在此直接指定皮刀魚安全密度或全套參數。
- 若溶氧下降、魚隻浮頭／失衡、急促呼吸、擦撞增加，立即停止裝魚、加強備援供氧、增加安全換水並降低密度。

## 7. 4–7天操作原則
- 捕獲與轉移：盡量縮短離水時間，避免乾手接觸、擠壓、吊鉤傷魚及硬網摩擦；分批、低落差轉移。
- 入槽前：先比對溫度與鹽度，逐步適應，避免突然變化。
- 餵食：運輸／暫養初期先不餵，待魚隻穩定後由水產專業人員依攝食反應與水質決定是否少量餵食；不餵活餌或未確認來源之餌料。殘餌須立即移除。
- 每班巡查魚隻行為、死亡數、泵浦、曝氣、溢流與濾網；每日記錄死亡率及水質。
- 槽體清潔與排污不得讓污水回流至取水口。

## 8. 分階段驗證
1. 空槽測試：漏水、溢流、排水、防浪、泵浦備援及電力測試。
2. 無魚航行測試：在港內及經核准的安全海況下，確認水體晃動、槽體固定、取排水及船舶操縱性。
3. 小量試養：先以20–30尾作生物適應與存活測試；這是試驗批次，不代表已證實安全密度。
4. 逐步增加：試驗數據顯示水質、魚體狀況及船舶穩性皆合格後，才逐批提高數量；500–600尾是目標，不是預先核定容量。

## 9. 必須取得的現場資料
- 船舶總長、船寬、船深、總噸位、最大載重／核定載重、現有吃水及穩性資料。
- 暫養艙內長、寬、深、艙底形狀、艙壁厚度、艙口及現有排水配置。
- 魚隻預計平均體長與平均重量（至少抽樣30尾）。
- 航行時數、海況、船速、船上可用電壓／發電機容量。
- 現有取水口、排水口、主機排氣及艙底水位置。

## 10. 法規與安全
漁業署說明，主甲板以下魚艙空間或功能變更可能涉及漁船改造；應先向船籍所在地漁業主管機關及航政機關確認申請與檢查要求。施工前不得擅自變更船艙用途或結構。
氧氣瓶、電氣、海水管路與排水需符合船舶安全要求。正式設計須由合格船舶專業人員審查。
